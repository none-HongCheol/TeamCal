개인정보처리방침

TeamCal (Windows 데스크톱 위젯) · 시행일 2026년 11월 12일

TeamCal(이하 "위젯")은 팀 휴가 캘린더와 사용자의 구글 캘린더 일정을 Windows 바탕화면에서 보여주는 개인용 도구입니다. 위젯은 별도의 서버를 운영하지 않으며, 사용자의 정보를 위젯 제작자에게 전송하거나 수집하지 않습니다.

1. 구글 계정에서 사용하는 정보

  • 캘린더 목록과 일정(제목, 시간, 장소, 색상): 위젯 화면에 "내 일정"을 표시하기 위해 읽습니다.
  • 일정 추가: 사용자가 위젯에서 직접 "일정 추가"를 눌렀을 때에만 사용자가 입력한 일정을 사용자의 구글 캘린더에 만듭니다. 기존 일정을 수정하거나 삭제하지 않습니다.
  • 새 캘린더: 사용자가 위젯에서 "새 캘린더"를 만들 때에만 사용자의 구글 계정에 캘린더를 만듭니다.
  • 공유 링크: 사용자가 "링크 복사"를 누르면 일정 내용을 담은 구글 캘린더 링크를 사용자의 클립보드에 복사합니다. 위젯이 이 링크를 다른 곳에 보내지 않습니다.
  • 요청하는 권한: calendar.readonly, calendar.events, calendar.app.created

2. 정보의 저장

  • 구글 일정 데이터는 화면 표시를 위해 실행 중인 위젯의 메모리에만 있으며, 별도로 저장하거나 외부로 보내지 않습니다.
  • 구글 로그인 유지를 위한 토큰은 사용자 PC에만 저장되며, Windows 사용자 계정으로 암호화(DPAPI)됩니다.
  • 팀 휴가 데이터는 팀 휴가 캘린더 서비스(Supabase)에 저장되며, 팀 휴가 캘린더 웹사이트와 동일한 방식으로 처리됩니다.

3. 제3자 제공

위젯은 사용자의 정보를 판매하거나 제3자에게 제공하지 않습니다. 구글 API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 연결 해제와 삭제

  • 위젯 메뉴(⋯) → 내 일정 → "연결 해제"를 누르면 PC에 저장된 로그인 토큰이 삭제됩니다.
  • 구글 계정 쪽 권한은 Google 계정 → 보안 → 서드 파티 액세스에서 언제든 삭제할 수 있습니다.
  • 위젯을 삭제하려면 %LOCALAPPDATA%\TeamLeaveWidget 폴더를 지우면 모든 로컬 데이터가 삭제됩니다.

5. 문의

이 위젯은 팀 내부용으로 제작되었습니다. 문의는 위젯 제작자에게 해 주세요.
